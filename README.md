# Goxide next

Experimental capabilities for Goxide live here. This initial repository contains
only documentation and local-file ignore rules; no APIs, implementation, module
manifest, dependencies, or release are provided yet.

Use `main` as the starting point for future work. Experimental API scope and
implementation will be defined separately as work is agreed.

Related repositories:

- [goxide](https://github.com/goxide-lang/goxide): compiler and language design.
- [std](https://github.com/goxide-lang/std): shared core types.
- [serde](https://github.com/goxide-lang/serde): serialization protocols and formats.
